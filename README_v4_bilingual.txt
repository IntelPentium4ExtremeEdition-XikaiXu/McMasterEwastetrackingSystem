McMaster E-Waste Map Tracker v4 / 麦马电子废物箱地图追踪器 v4

English is the default language. Use the Language menu in the top-right area to switch to 中文 at any time.
默认语言为英语。使用顶部的 Language 下拉菜单可以随时切换到中文。

Install / 安装：
  sudo apt install python3-tk python3-pil.imagetk
Run / 运行：
  python3 e_waste_tracker_v4_bilingual.py

Keep mcmaster_ewaste_map.png beside the Python file.
请保持地图文件和 Python 文件位于同一目录。
